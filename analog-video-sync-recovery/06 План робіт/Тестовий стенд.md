# Тестовий стенд

## Обладнання
| Що | Навіщо | Варіант |
|---|---|---|
| Осцилограф ≥ 50 MHz, 2 канали, бажано video trigger | Рівні, джитер, затримка, glitch ключа | будь-який DSO; для джитеру краще логічний аналізатор на виході сепаратора |
| VTX + VRX (наші реальні) | джерело справжнього шуму | + **ступінчастий атенюатор** (SMA, 0–60 dB) між ними замість «відходити далеко» — повторювані умови |
| Камера PAL/NTSC | реальний джитер камери | дешева і дорога — порівняти |
| Raspberry Pi Pico ×2 | генератор еталонного sync/патернів; логер міток CSYNC | pico-pattern / pico-composite + модифікація «керовані пропадання» |
| MinimOSD / AT7456E модуль | тест H4 | $3 |
| EasyCap UTV007 | запис відео для звітів | не еталон таймінгу |
| Монітор(и): наш + 1–2 інших (окуляри, Feelworld) | сумісність декодерів | |
| Макетна плата з 75 Ω роз'ємами, THS7314 на перехіднику | етап 1 | |

## Сценарії
1. **Чистий сигнал** (VTX поруч, атенюатор 20 dB): базові рівні, PASS.
2. **Плавне погіршення**: атенюатор 40→60 dB кроками по 2 dB; на кожному кроці 30 с: частка замінених рядків (з логу), стан монітора (A/B).
3. **Різке пропадання**: вимкнути VTX на 0.5 / 2 / 5 / 10 с → час до COAST, поведінка монітора, час повернення до LOCKED.
4. **Імпульсні завади**: інший VTX на сусідньому каналі вмикається на 100 ms — хибні sync.
5. **Синтетика** (Pico-генератор із керованими дефектами): пропустити N рядків sync; зсунути sync на ±X мкс; додати хибний імпульс посеред рядка; прибрати V-sync на 1 поле; змінити період на +0.3 % (камера без кварцу). Для кожного — очікувана реакція трекера задокументована і перевірена.
6. **Довготривалий**: 1 година на межі (сценарій 2, фіксований крок) — жодного зависання, лог без розривів.

## Метрики (усі пишемо в лог)
- `replaced_ratio` — частка рядків із замінним sync за секунду.
- `state_transitions` — кількість переходів LOCKED↔COAST за хвилину (багато = «дрижить» гістерезис).
- `period_est` — оцінений період; його стабільність = якість інтегральної гілки.
- `phase_err_rms` — |t_next − t_real| на валідних імпульсах.
- Для монітора: секунди «корисної картинки» на подію (експертна оцінка з DVR-запису, двоє людей незалежно).

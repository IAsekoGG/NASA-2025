# Блок 2 — Сепарація синхро

## Мета
Отримати цифрові CSYNC (і VSYNC/BP/odd-even як допоміжні) з мінімальним джитером. **Не** намагатись зробити його «розумним» — розум у Блоці 3.

## Вхід / Вихід
- Вхід: вихід B Блоку 1.
- Вихід: CSYNC (активний низький), VSYNC, BURST/BP gate, ODD/EVEN — логічні рівні 3.3 V на GPIO MCU.

## Реалізація
- v1: LM1881 (клон), RSET 680 kΩ, 0.1 µF; вихід через дільник/буфер до 3.3 V.
- v2: LMH1981 або EL4583 (50 % slice, є вихід «no signal»).
- v3 (гібрид): компаратор із порогом від ЦАП MCU (адаптивний поріг за виміряним рівнем гасіння) або АЦП 10–20 MSPS + цифровий детектор ([[Варіант C - повна оцифровка]]).
Деталі мікросхем: [[Сепаратори синхроімпульсів]].

## Критерій приймання
- [ ] На чистому сигналі: період CSYNC 64.000 ± 0.01 мкс, джитер фронту (RMS) ≤ 20 нс (LM1881) / ≤ 5 нс (LMH1981).
- [ ] На сигналі з шумом (SNR ~20 dB, атенюатор між VTX і VRX): рахуємо частку рядків із рівно одним імпульсом у вікні ±2 мкс — записати як базову метрику для порівняння з трекером.
- [ ] VSYNC присутній у кожному полі, парність ODD/EVEN чергується на чистому сигналі.

## Ризики
- Хибні імпульси від хроми/шуму без ФНЧ — обов'язково фільтр.
- LM1881 без clamp на вході «плаває» по рівню при зміні середньої яскравості — тому Блок 1 попереду.

# Блок 5 — Вставка sync (аналоговий ключ)

## Мета
Фізично замінити інтервал sync у відеотракті рівнем «sync tip», коли Блок 3 каже, що вхідний імпульс невалідний або відсутній; в інший час — пропускати вхід без змін.

## Логіка керування
```
SW = (state == COAST) ? SYNC_GATE
   : (state == LOCKED && !input_valid) ? SYNC_GATE
   : 0                                     # PASS
```
Опція «завжди замінювати у LOCKED» (SW = SYNC_GATE): дає ідеально рівний sync навіть на хорошому сигналі (усуває джитер камери), але тоді якість повністю залежить від точності трекера. Зробити перемикачем; за замовчуванням — вимкнено (принцип «не нашкодь»).

## Реалізація
- TS5A3159 (або ADG719): IN1 = відео з Блоку 1, IN2 = V_SYNC_LEVEL, COM → Блок 6, керування від AND(SW-логіка) — краще зробити AND у PIO/логіці MCU, щоб не додавати мікросхем.
- V_SYNC_LEVEL = рівень гасіння тракту − 300 mV (при 1 Vpp у тракті) — від ЦАП MCU через RC та буфер, або підстроювальний резистор від опорної напруги. **Калібрується** на етапі 1 по осцилографу: вставлений sync має збігатись за рівнем із вхідним ± 20 mV.
- Другий ключ (опційно): keyed back-porch clamp у Блоці 1 від `BP_GATE`.

## Критерій приймання
- [ ] Стрибок (glitch) при перемиканні ≤ 20 mV, тривалість ≤ 50 нс (осцилограф, режим PASS→REPLACE на чистому сигналі).
- [ ] Вставлений імпульс: рівень −300 ± 20 mV відносно гасіння, фронти ≤ 100 нс, позиція збігається з реальним sync ± 50 нс (тест «forced replace» на чистому сигналі — картинка не має зміститись).
- [ ] У режимі PASS: наскрізна АЧХ і рівні не відрізняються від «прямого кабелю» більше ніж на 0.5 dB / 20 mV.
- [ ] Тест «forced replace на 100 % рядків» на чистому сигналі: монітор показує ту саму картинку, колір збережений (burst не зачеплено).

## Ризики
- Рівень sync не збігається з вхідним → на межах PASS/REPLACE «сходинка» рівня гасіння → clamp монітора смикається → смуги яскравості. Лікується clamp на вході (стабільний рівень) і калібруванням.
- Ключ закривається пізніше 5.3 мкс → зачепили burst → мерехтіння кольору.
